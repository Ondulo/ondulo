# Ondulo

Audio-reactive 2D and 3D visualizers for React. Easy to add, easy to customize.

Early development. Nothing is published to npm yet. Documentation will live at [ondulo.dev](https://ondulo.dev).

## Development

Requires Node.js 20 or newer and pnpm.

```sh
pnpm install
pnpm test
pnpm typecheck
pnpm build
```
